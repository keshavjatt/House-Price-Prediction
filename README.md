# 🏠 House Price Prediction App

This project is a machine learning-based real estate price prediction application that estimates house prices based on key property features.

---

## 🎯 Problem Statement

To build a predictive model that estimates house prices based on property characteristics such as:

- Area (square feet)
- Number of bedrooms
- Number of bathrooms
- Number of stories (floors)
- Parking spaces

This helps home buyers, sellers, and real estate agents with accurate price estimation, market analysis, and investment decisions.

---

## 🏥 Real-Time Business Use Cases

- **Property Valuation for Buyers & Sellers**
- **Real Estate Investment Analysis**
- **Mortgage & Loan Assessment**
- **Construction Cost Estimation**

---

## 🚀 Features

- Linear Regression-based price prediction model
- Clean, interactive Streamlit web interface
- Responsive form with intuitive input controls
- Real-time price prediction with visual feedback
- Model training and evaluation scripts
- Easy deployment with minimal dependencies
- Formatted price display with Indian currency (₹)

---

## 🧾 How to Run this Project

- git clone https://github.com/keshavjatt/House-Price-Prediction.git 
- cd House-Price-Prediction
- pip install -r requirements.txt
- python -m streamlit run app.py
